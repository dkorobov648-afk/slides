# Конструктор презентаций

Собирайте слайды из готовых блоков и скачивайте готовый файл PowerPoint (.pptx).

**Открыть:** https://dkorobov648-afk.github.io/slides/

- 9 типов слайдов: титульный, раздел, текст, список, две колонки, картинка, цитата, цифры, финал
- у каждого типа — несколько раскладок
- 14 тем, свой акцентный цвет и шрифты, украшения, свой фон (цвет или картинка)
- черновик сохраняется в браузере сам

Вся страница — один файл `index.html`, ничего устанавливать не нужно.
